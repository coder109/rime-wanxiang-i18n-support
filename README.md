# 万象拼音 · 多语言字母

在 [万象拼音](https://github.com/amzxyz/rime-wanxiang) 上增加德文、法文字母输入。中文拼音、词库和语法模型仍用万象，这份仓库只额外处理英文状态下的特殊字母。个人使用优先。

字母输入由 `lua/wanxiang/german_compose.lua` 完成，挂在 `wanxiang.schema.yaml` 的处理器最前面。

---

## 当前用法

| 用法 | 条件 | 操作 | 结果 |
| --- | --- | --- | --- |
| 选取表情 | 出现表情等提示 | `.` | 上屏提示中的表情 |
| 普通句号 | 没有匹配到提示 | `.` | 。 |
| 字母输入 | 英文状态 | `Ctrl+;` 然后 `a` / `Shift+a` | ä / Ä |
| 字母输入 | 英文状态 | `Ctrl+;` 然后 `o` / `Shift+o` | ö / Ö |
| 字母输入 | 英文状态 | `Ctrl+;` 然后 `u` / `Shift+u` | ü / Ü |
| 字母输入 | 英文状态 | `Ctrl+;` 然后 `s` / `Shift+s` | ß / ẞ |
| 字母输入 | 英文状态 | `Ctrl+;` 然后 `e` / `Shift+e` | é / É |
| 字母输入 | 英文状态 | `Ctrl+;` 然后 `c` / `Shift+c` | ç / Ç |
| 字母输入 | 英文状态 | `Ctrl+;` 然后 `` ` ``，再按 `a` `e` `u` | à è ù |
| 字母输入 | 英文状态 | `Ctrl+;` 然后 `6`，再按 `a` `e` `i` `o` `u` | â ê î ô û |
| 字母输入 | 英文状态 | `Ctrl+;` 然后 `'`，再按 `e` `i` `y` | ë ï ÿ |
| 字母输入 | 英文状态 | `Ctrl+;` 然后 `7`，再按 `a` `o` | æ œ |
| 取消字母输入 | 英文状态 | `Ctrl+;` 后按了表里没有的键 | 取消，该键按普通英文处理 |

`Ctrl+;` 每次只生效一个字符，上屏后回到普通英文输入。按住 Shift 上屏对应大写。句号上屏键对应 `super_tips/tips_key: "period"`。

## 使用方法

### 安装

需要能运行 Lua 的 Rime 前端，例如 Windows 上的小狼毫、macOS 上的鼠须管、Linux 上的 fcitx5。万象 Pure 不带 Lua，用不了这里的字母输入。

1. 安装并部署一套万象拼音 Base。词库、模型和双拼切换以[万象文档](https://amzxyz.github.io/rime-wanxiang/)为准。
2. 把本仓库的 `lua/wanxiang/german_compose.lua` 放到用户目录的同名路径。
3. 确认 `wanxiang.schema.yaml` 里，`engine/processors` 的第一项是：

```yaml
- lua_processor@*wanxiang.german_compose
```

4. 重新部署。

已经在用万象时，不必整份覆盖用户目录。只合并上面的脚本和这一行处理器，避免盖掉自己的 `custom` 配置和用户词库。

### 打中文

中文状态和原来的万象一样：全拼或双拼、声调筛选、超级提示都不变。这个脚本只在英文状态里看 `Ctrl+;`，不会吃掉拼音编码。

### 打德法字母

先切到英文状态，再按一次 `Ctrl+;`，然后按[当前用法](#当前用法)里的键。

直接字母，按一下就上屏：

| 按键 | 上屏 |
| --- | --- |
| `Ctrl+;` `o` | ö |
| `Ctrl+;` `Shift+o` | Ö |
| `Ctrl+;` `e` | é |
| `Ctrl+;` `c` | ç |

带重音的字母要再按一个键。重音键本身不要按 Shift，`6` `'` `7` 就是键面上的字符：

| 按键 | 上屏 |
| --- | --- |
| `Ctrl+;` `` ` `` `e` | è |
| `Ctrl+;` `6` `a` | â |
| `Ctrl+;` `'` `e` | ë |
| `Ctrl+;` `7` `o` | œ |

大写只加在最后那个字母上。例如 `` ` `` 然后 `Shift+a` 得到 À，`6` 然后 `Shift+e` 得到 Ê。

每次 `Ctrl+;` 只负责一个字符。上屏之后回到普通英文，下一个特殊字母要再按一次 `Ctrl+;`。按下表里没有的键会取消这次输入，那个键仍按普通英文处理。按 Shift、Ctrl 本身不会取消。

### 用句号选表情

超级提示打开时，候选旁边如果出现表情等提示，按 `.` 上屏提示内容。没有提示时，`.` 仍是句号「。」。开关是 `Control+t`。上屏键在配置里是 `super_tips/tips_key: "period"`。

### 改完之后

改了脚本或方案文件，要重新部署才会生效。小狼毫可以在托盘图标里部署，也可以运行 `WeaselDeployer.exe /deploy`。
